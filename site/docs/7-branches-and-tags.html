7. Branches and tags

  • Create a branch: toolbar Branch (or right-click a commit → New branch here…). Leave Start from empty to branch from where you are. Tick Check out to switch to it immediately.
  • Switch branch: double-click it in the sidebar (or right-click → Check out). Remote branches are checked out as local tracking branches. If you have uncommitted changes that would be overwritten, the app tells you and offers to stash.
  • Rename / delete: right-click the branch. Deleting a branch that isn't fully merged requires ticking the box Delete even if it is not fully merged. Remote branches can be deleted from the server via Delete from server….
  • Tags: toolbar Tag (or right-click a commit). Add a message to create an annotated tag. Right-click a tag to push it to the server or delete it (locally).
