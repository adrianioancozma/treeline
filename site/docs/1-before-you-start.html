1. Before you start

  • Git must be installed (version 2.30 or newer) and available on your PATH. Check by running git --version in a terminal. Windows: download from https://git-scm.com. macOS: run xcode-select --install in Terminal, or brew install git. Linux: sudo apt install git (or your distribution's equivalent). The app also looks in Git's usual install folders on Windows. If it still cannot find Git, it says so and offers Locate Git…: choose the Git program (git.exe, normally in C:\Program Files\Git\cmd) and the app remembers it. You can change this later in Settings (the gear icon in the top bar, or the command palette).
  • Version and updates. The version number is at the bottom right of the window and in Settings. The app checks for a newer version when it starts and tells you if there is one. You can also use Settings → Check for updates. Nothing is installed until you press Install and restart.
  • Tell Git who you are once per computer, otherwise commits are refused:
    git config --global user.name  "Your Name"
git config --global user.email "you@example.com"

Signing in

The app uses whatever Git is already set up with:

  • HTTPS remotes – the first time Git needs a password or token, your operating system's credential manager (Git Credential Manager on Windows/macOS) opens a sign-in window and remembers the result.
  • SSH remotes – your SSH key must be loaded (ssh-add -l lists loaded keys) and its public half added to your account on the server.

If a fetch/push fails with an authentication error, the app explains it and shows these steps (see section 13).
