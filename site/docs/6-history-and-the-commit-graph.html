6. History and the commit graph

Open History (sidebar).

  • Each row is a commit: graph lines on the left, then message, author, date, short ID. Coloured tags are branches (green), remote branches (purple), tags (amber) and where you are (blue = current branch).
  • The top row Uncommitted changes appears when you have local changes; click it to jump to File status.
  • Click a commit to see its details and the files it changed; click a file to see that file's diff.
  • Search box: finds commits whose message contains your text (plain text, not a pattern). Untick All branches to show only the current branch's history.
  • Highlight a branch: click a branch, remote branch or tag in the sidebar — the graph scrolls to its tip and highlights every commit reachable from it; everything else is dimmed. Click the ✕ on the “Highlighting …” chip to clear it.
  • Right-click a commit for: copy ID, check out, new branch/tag here, cherry-pick, revert, merge into current, reset the current branch to here (soft / mixed / hard), and interactive rebase from here.
  • Long histories load in pages as you scroll.
  • Compare two commits: click one commit, then hold Ctrl (Cmd on a Mac) and click a second one. The panel shows what changed between them (older → newer), file by file. Ctrl+click the second commit again, or press Clear, to go back to a single commit.
  • History of one file: right-click a file (in File status, or in a commit's list of changed files) and choose File history…. You see every commit that changed that file, even before it was renamed, and the change each one made.
  • Who changed each line (Blame): right-click a file and choose Blame…, or switch to the Blame tab in the file history window. Each line shows who last changed it, when, and in which commit; click that name to jump to the commit in the file's history. From a commit's file list, Blame at this commit… shows the file as it was then.
